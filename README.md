# سامانه رزرو آنلاین سالن

این پروژه یک سامانه تحت وب برای مدیریت و رزرو آنلاین سالن‌های مختلف (مانند سالن‌های ورزشی، همایش و...) است که با استفاده از فریم‌ورک قدرتمند **Django** ساخته شده است.

## ✨ قابلیت‌های کلیدی

- **احراز هویت پیامکی:** ثبت‌نام و ورود کاربران از طریق شماره موبایل و کد تایید یکبار مصرف (OTP).
- **مدیریت کامل سالن‌ها:** افزودن، ویرایش و مدیریت اطلاعات سالن‌ها به همراه گالری تصاویر.
- **سیستم رزرو پیشرفته:** تقویم تعاملی برای مشاهده زمان‌های پُر و خالی و جلوگیری از رزروهای همزمان.
- **پنل مدیریت حرفه‌ای:** پنل ادمین زیبا و کاربرپسند با قابلیت‌های زیر:
    - مدیریت کامل کاربران، سالن‌ها و رزروها.
    - تایید یا رد دسته‌جمعی رزروها.
    - ثبت رزرو دستی توسط مدیر.
    - **گزارش‌گیری پیشرفته** با فیلترهای مختلف (بازه زمانی، سالن، وضعیت).
    - **خروجی PDF** از گزارش‌ها.
- **داشبورد کاربری:** مشاهده و مدیریت رزروها، لغو یا ویرایش زمان رزرو.
- **رابط کاربری مدرن:** طراحی واکنش‌گرا (Responsive) با استفاده از Bootstrap 5 و کامپوننت‌های مدرن جاوااسکریپت.

قبل از شروع، مطمئن شوید ابزارهای زیر روی سیستم شما نصب هستند:

1.  **Python (نسخه ۳.۸ یا بالاتر)**
2.  **Git** (برای دانلود کدها)
3.  **کتابخانه‌های سیستمی برای ساخت PDF:**

    - **در Windows/macOS:**

## 🚀 راهنمای راه‌اندازی پروژه

برای راه‌اندازی پروژه روی سیستم محلی خود، مراحل زیر را دنبال کنید:

**۱. دریافت کدها**
```bash
git clone <URL-پروژه-شما>
cd <نام-پوشه-پروژه>
```

**۲. ایجاد و فعال‌سازی محیط مجازی (Virtual Environment)**
این کار باعث ایزوله شدن پکیج‌های پروژه می‌شود.
```bash
# ساخت محیط مجازی
python -m venv venv

# فعال‌سازی در Windows
.\venv\Scripts\activate

# فعال‌سازی در Linux/macOS
source venv/bin/activate
```

**۳. نصب پکیج‌های مورد نیاز**
تمام کتابخانه‌های پایتون که پروژه به آن‌ها نیاز دارد، با دستور زیر نصب می‌شوند:
```bash
pip install -r requirements.txt
```

**۴. تنظیم متغیرهای محیطی**
فایل `.env.example` را به `.env` کپی کرده و مقادیر آن را تکمیل کنید.
```bash
# در Windows
copy .env.example .env

# در Linux/macOS
cp .env.example .env
```
سپس فایل `.env` را باز کرده و یک مقدار برای `SECRET_KEY` قرار دهید. برای ساخت کلید جدید می‌توانید از دستور زیر استفاده کنید:
```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

**۵. ساخت پایگاه داده**
این دستور جداول مورد نیاز برنامه را در دیتابیس می‌سازد.
```bash
python manage.py migrate
```

**۶. ساخت کاربر مدیر (Superuser)**
برای دسترسی به پنل مدیریت، یک کاربر ادمین بسازید و اطلاعات خواسته‌شده را وارد کنید.
```bash
python manage.py createsuperuser
```

**۷. اجرای سرور**
تبریک! پروژه آماده است.
```bash
python manage.py runserver
```
